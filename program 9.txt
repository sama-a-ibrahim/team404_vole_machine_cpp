; ---------------------------------------------
; Vole Machine Program 1 (Alternative)
; Purpose: Load 0xAA and 0x55, perform bitwise 
; XOR, and display the result (0xFF) on screen.
; ---------------------------------------------
20AA ; Load immediate value AA into register 0
2155 ; Load immediate value 55 into register 1
9201 ; XOR registers 0 and 1, put result in register 2
32FF ; Store register 2 into memory location FF (screen output)
C000 ; Halt execution
